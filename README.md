# 🏦 Bank Management System with ATM Simulation

A Java-based desktop application that simulates basic banking operations through an interactive graphical user interface. The project uses Java Swing and AWT for frontend development and MySQL for database management.

## 📌 About the Project

The **Bank Management System with ATM Simulation** is designed to provide a simple and user-friendly banking experience. It allows users to register for a bank account, securely log in using their card number and PIN, and perform essential banking operations.

The project focuses on implementing core Java concepts, GUI development, database connectivity, and object-oriented programming.

## ✨ Features

- **User Authentication:** Login using card number and PIN.
- **Account Registration:** Register new customers and create bank accounts.
- **Balance Enquiry:** Check the current account balance.
- **Cash Deposit:** Deposit money into an account.
- **Cash Withdrawal:** Withdraw money from an account.
- **Mini Statement:** View recent transaction details.
- **PIN Management:** Change the ATM PIN.
- **Database Management:** Store and retrieve customer and transaction information using MySQL.

## 🛠️ Technologies Used

| Technology | Purpose |

## ⚙️ Prerequisites

Before running the project, make sure you have installed:

- Java JDK 17 or later
- MySQL Server
- Maven
- An IDE such as IntelliJ IDEA or Eclipse
